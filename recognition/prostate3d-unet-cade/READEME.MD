# Prostate 3D Segmentation using a 3D U-Net

## Problem
This Problem this project undertakes is segmentating downsampled 3D Prostate data using a enhanced U-Net architecture 
to achieve a Dice similarity coeffecient (DSC) of at least 0.7 on the test set.

To do this two models will be implemented, 

1. A baseline simple 3D U-Net 
2. An extended 3d U-Net utilising CAN3D.
